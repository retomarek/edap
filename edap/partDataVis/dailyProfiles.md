# Daily Profiles

Daily profile visualizations show how a variable changes over the course of a day. They are essential for understanding usage patterns, occupancy behavior, and system operation.

## Recipes

- **Overview** — Mean daily profile with confidence band for each season and weekday
- **Overlaid Profiles** — All days drawn on top of each other
- **Mean Profile** — One mean daily profile per weekday
- **Decomposed Profile** — Weekly pattern with the slow trend removed
